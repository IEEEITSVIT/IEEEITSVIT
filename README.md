## About us

We are the **IEEE Information Theory Society student chapter at VIT Vellore**, founded in 2023. We run workshops,
hackathons, talks and the **ic-ETITE** international conference, and build open tools for VIT students.

| 60+ members | 10+ events | 9 domains | Est. 2023 |
| :---: | :---: | :---: | :---: |

**Domains:** Technical · Project · Research & Development · Design & Creative · Editorial · Publicity · Events &
Management · Out-Reach · Finance

## Projects

| Project | What it is | Built with |
| --- | --- | --- |
| [**IEEE-ITS-VIT**](https://github.com/ieeeitsvitscore-ai/IEEE-ITS-VIT) | Our website and admin studio — content, recruitment portal, hackathon portals with judging and certificates, bulk email. [Live ↗](https://ieee-its-vit.vercel.app) | React · Vite · Cloudflare D1 · Vercel |
| [**ic-etite28**](https://github.com/ieeeitsvitscore-ai/ic-etite28) | Website for **ic-ETITE'28**, the third International Conference on Emerging Trends in Information Technology and Engineering | Next.js · TypeScript · Tailwind |
| [**CREDITS-AND-FFCS-PLANNER**](https://github.com/ieeeitsvitscore-ai/CREDITS-AND-FFCS-PLANNER) | Brings a VIT student's VTOP data together — grades, CGPA, credits, curriculum progress — and builds clash-free FFCS timetables | Cloudflare Workers · D1 · JavaScript |
